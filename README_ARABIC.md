# نظام إدارة المكتبة

نظام إدارة المكتبة هو حل ويب شامل مصمم لتبسيط الإجراءات الإدارية المتعلقة بإدارة مكتبة الكلية. ويغطي الفهرسة، وتتبع النسخ الفعلية، والاستعارة والإرجاع، وتسجيل الغرامات والتلف.

## نظرة عامة

يعتمد النظام على [إطار Frappe](https://frappeframework.com/) المعروف بمرونته وقوته في بناء تطبيقات الويب المعقدة. ويلبي احتياجات المكتبة الأساسية، ومنها:

* إدارة فهرس المراجع: إدارة الكتب والمجلات والأبحاث والرسائل العلمية ومشاريع التخرج والمواد الصوتية والمرئية والإلكترونية، مع المؤلفين والناشرين والتصنيفات.
* تتبع النسخ: تتبع كل نسخة فعلية من المرجع، وباركودها، وحالتها (متاح، غير متاح، تالف).
* الاستعارة والإرجاع: معالجة استعارة النسخ وإرجاعها للموظفين والطلاب، مع مدة إعارة وحد أقصى للاستعارات لكل دور.
* الغرامات والتلف: تسجيل غرامات التأخير (تنشئها مهمة يومية) وتقارير التلف مع غراماتها.
* الموقع الفعلي: تنظيم النسخ حسب قسم المكتبة والمنطقة والرف.
* طلبات التوريد: إدارة طلبات التوريد وبنودها.

## التقنيات المستخدمة

* الإطار: [Frappe](https://frappeframework.com/) (المستهدف الإصدار 15)
* الخلفية: [Python](https://www.python.org/) الإصدار 3.10 أو أحدث
* الواجهة الأمامية: JavaScript (نماذج Frappe) وVue (الكتالوج العام، في مستودع منفصل `library_vue`)
* قاعدة البيانات: [MariaDB](https://mariadb.org/)

# Known issues and open decisions

Found by reading the code. The app has **not** been run on a Frappe site in this review, so this list is from the code, not from runtime testing.

## Behaviour

1. **Overdue loans cannot be returned from the form.** `item_borrowing.js` shows the Returned / Damage / Extend buttons only when `status == "In Progress"`; once the daily job sets *Overdue* the buttons disappear. Suggested: also show them for *Overdue*.
2. **No fine on late return.** The *Delay* fine is created only by the daily job. Returning late before the job runs creates none.
3. **`actual_retrieval_date` is never set** by the Returned button, so the real return date is not recorded.
4. **Two borrowing flows.** `Item Borrowing` (Employee/Student, limits, fines) and `Library Transaction` (membership-based) both change the copy status. Decide whether to keep both.
5. **`Magazine` can be selected in `Library Transaction`**, but `Item Copy` only accepts Book and Graduation Project, so a magazine has no copies to issue.
6. **Item Copy identifier** is no longer generated by the form (the old JS was commented out); `copy_identifier` must be typed, and the copy barcode needs it.
7. **`Book.barcode`** is entered manually (automatic generation is commented out). `Graduation Project` generates one from the title initials + timestamp.

## Data model

8. **Wrong field types:** `Research Paper.keywords`, `These And Dissertation.degree` and `.supervisors` are *Date* fields; `Research Paper.authors` links to *Audio Item*.
9. **Unused doctypes:** `Department`, `Library Indexing`, `Library Section` are not referenced by other doctypes.
10. **Naming:** `library_manegment` (spelling), `These And Dissertation`, `Unactivation Book`, `Employee.name1`. Renaming apps and doctypes with data needs a migration plan.

## Security / deployment

11. The two catalogue APIs are public (`allow_guest=True`) and `get_all_books` has no paging.
12. The Vue front end has `http://localhost:8001` hard-coded (separate repository).
13. `license.txt` still has the template copyright line.

## Fixed while consolidating

* `Library Transaction` used the status `On Loan`, which no longer exists in `Item Copy`; it now uses `Unavailable`. Debug `log_error` calls were removed.
* `Library Member` / `Library Membership` were referenced but missing on `develop`; restored from `manar-branch`.
* `Student.full_name` joined the name parts without spaces.
* `graduation_project.py` used `json` without importing it.
* `get_book_details` hard-coded `localhost:8001` and failed when a book had no cover image.
* `Unactivation Book`: removed a call to a misspelled field (`book_copy43`) and moved the status change from every save to submit / cancel.
* Tracked `__pycache__/*.pyc` files were removed from the repository.
